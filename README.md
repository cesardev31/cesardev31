## Sistemas en producción

### Orvix · CRM + telefonía IP

Producto SaaS desarrollado end-to-end junto a un socio. Además del CRM,
construí un servicio independiente de señalización y media para llamadas
PSTN/SIP con **puente RTP/WebRTC, control y streaming gRPC, IVR, grabación,
pruebas de carga y despliegue en AWS**.

El ecosistema integra PostgreSQL, Meta/WhatsApp, pagos, notificaciones,
WebSockets, contenedores y automatización de despliegues. El código de producto
permanece privado; los proyectos públicos de esta página muestran el mismo nivel
de ingeniería con evidencia verificable.
